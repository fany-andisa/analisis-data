Fungsi Logika IF

Menguji syarat tertentu untuk menentukan dua kemungkinan hasil (Benar atau Salah).

=IF(E2>=50; "Laris"; "Normal")

Pivot Table

Alat peringkas data interaktif untuk mengelompokkan dan menjumlahkan data otomatis tanpa mengetik rumus.

Insert → PivotTable → Atur Rows & Values

Kunci Jawaban Referensi Guru
